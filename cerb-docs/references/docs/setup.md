The **setup** page in the top right of the navigation bar provides a central location for administrators to configure Cerb and any plugins that have been installed.

The page is divided into sections, each with a blue menu designated by a downward-pointing arrow. You can hover over each menu to display the configuration options for that section.

- **Configure**
  - Branding
  - Cache
  - License
  - Localization
  - Scheduler
  - Search

- **Security**
  - Configure
  - Authentication
  - Sessions

- **Records**
  - Avatars
  - Custom Fields
  - Snippets

- **Team**
  - Configure
  - Roles
  - Groups
  - Workers

- **Mail**
  - **Incoming Mail**
    - Settings
    - Mailboxes
    - Filtering
    - Routing
    - HTML
    - Import
    - Failed Messages
    - External Relay

  - **Outgoing Mail**
    - Email Transports
    - Sender Addresses
    - Settings
    - Automated Email Templates
    - Queue

- **Packages**
  - Library
  - Import

- **Storage**
  - Overview
  - Profiles
  - Objects

- **Developers**
  - Automation Logs
  - Automation Scripting Tester
  - Data Query Tester
  - Export Bots
  - Icon Reference
  - OAuth2 Token Generator
  - Platform

- **Plugins**
  - Configure
