**record.viewed** automation events are invoked after a worker views a record profile.

# Placeholders

The automation event dictionary starts with the following values:

| Key | Type | Notes |
| --- | --- | --- |
| `record_*` | record | The viewed record dictionary. Supports key expansion. |
| `worker_*` | record | The current worker dictionary. Supports key expansion. |

# Outputs

(none)
